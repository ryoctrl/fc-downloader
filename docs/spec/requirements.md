# 要件

## 機能要件

### F1. サービス選択 / ログイン
- F1.1 サイドメニューに対応サービスのアイコン一覧を表示する（使わないサービスは設定で非表示にできる）。
- F1.2 サービス選択で、当該サービスのトップ/ログインページを内蔵 WebView に表示する。
  サインイン用のポップアップ（例: Google でログイン）はアプリ内で開き、同じセッションに Cookie を残す。
- F1.3 Cookie・セッションはサービスごとに隔離し永続化する（`persist:<serviceId>`）。
- F1.4 ログイン状態を確認できる（`checkAuth`）。
- F1.5 セッション破棄（ログアウト相当）ができる。
- F1.6 WebView でログインを完了できないサービス向けに、セッション Cookie の値を貼り付けて
  ログインできる（Fantia / Fanbox / Patreon。Cookie 名と保存先ドメインはアプリ側で固定）。

### F2. ダウンロード設定
- F2.1 対象クリエイターを選択（未指定なら支援中すべて）。一覧に出ないクリエイターは、
  表示中のページから追加できる（Patreon）。
- F2.2 ファイル種別フィルタ（image / video / audio / file）。
- F2.3 同時ダウンロード数の指定。
- F2.4 重複スキップの ON/OFF。
- F2.5 投稿の公開日による期間指定: すべて / 直近 N 日 / 開始日〜終了日 / 前回以降
  （クリエイターごとに、前回最後まで完了した実行以降の投稿のみ）。
- F2.6 まだダウンロードしていない新着投稿があるクリエイターに「New」を表示する
  （ホームのフィードを持つ Fanbox / ci-en）。

### F3. 一斉ダウンロード
- F3.1 支援中コンテンツを列挙し、まとめてダウンロードする。Fantia は購入済みのショップ商品も対象にする。
- F3.2 進捗（合計/完了/スキップ/失敗、速度・残り時間、列挙中のクリエイター・ページ）をリアルタイム表示する。
- F3.3 実行中にキャンセルできる。
- F3.4 失敗したファイルは記録し、再実行で再取得できる。
- F3.5 複数サービスの実行をキューで順に処理する。全サイト一括実行と、毎日決まった時刻の定期実行ができる
  （アプリ起動中のみ。起動時に当日分が未実行なら追いかけて実行）。

### F4. 重複検知
- F4.1 台帳のキー `(serviceId, creatorId, postId)` とファイル単位の記録で取得済みを判定する
  （保存フォルダはキーにしない）。
- F4.2 メタデータ台帳と実ファイルの両方を確認する。
- F4.3 アプリ外で削除されたファイルを台帳から外す（台帳とディスクの照合）。

### F5. ライブラリ / ビューワー
- F5.1 台帳からライブラリ（サービス → クリエイター → 投稿）を構築し、グリッド/リストで一覧・絞り込みする。
- F5.2 投稿フォルダを OS のファイラで開ける。投稿の Web ページを外部ブラウザで開ける。
- F5.3 画像/動画/音声のインラインプレビューと画像のライトボックス。
- F5.4 zip を投稿フォルダ内に解凍できる。パスワード付き（ZipCrypto）は入力したパスワードを投稿ごとに記憶する。
- F5.5 PSD のレイヤー表示切り替え・画像書き出し・サムネイル生成。
- F5.6 お気に入り登録。

### F6. 設定
- F6.1 ダウンロード保存先ルートの変更。
- F6.2 既定の同時ダウンロード数。
- F6.3 保存フォルダ名のパターン（クリエイター / 投稿。[storage-and-dedup.md](storage-and-dedup.md)）。
- F6.4 PC ログイン時の自動起動。
- F6.5 表示言語（日本語 / English / 简体中文。初回は OS の言語から選ぶ）、テーマ。
- F6.6 起動時に新バージョンの有無を確認し、あれば通知する（ダウンロードは手動）。

## 非機能要件

- N1. **ローカル完結**: 対象サイト以外への通信は、新バージョン確認（GitHub API の読み取り）のみ。
  利用者のデータを外部へ送らない。
- N2. **セキュリティ**: `contextIsolation: true` / `nodeIntegration: false`。
  renderer は `window.api`（typed IPC）経由でのみ特権操作を行う。
- N3. **クロスプラットフォーム**: Windows を主対象とし、macOS（universal dmg）も配布する。
- N4. **耐障害性**: ダウンロード中断・失敗時もメタデータ整合を保ち、再開できる。
- N5. **拡張性**: 新規サイト追加は `Service` 実装 + 登録のみで完結する。
- N6. **パフォーマンス**: 大量投稿でもメモリを圧迫しない（ストリーミング書き込み）。
- N7. **対象サイトへの配慮**: アプリが自動で出すメタデータ要求はサービスごとに間隔を空ける
  （[security-and-legal.md](security-and-legal.md)）。
