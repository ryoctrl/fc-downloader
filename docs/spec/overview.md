# 概要

## プロダクト

fc-downloader は、ファンクラブ系支援サイトで **自分が支援している** コンテンツを
ローカル PC にダウンロードして保管・閲覧するためのデスクトップアプリ。

対象サイト（4 つとも実装済み。検証状況は [service-abstraction.md](service-abstraction.md#サイト別メモ)）:

- Fantia（支援中の投稿 + 購入済みのショップ商品）
- Pixiv Fanbox
- Patreon（投稿・メディアの取得は有料支援中アカウントでの確認が未了）
- ci-en

## 体験フロー

1. サイドメニュー（Rail）でサービス（Fantia など）を選択。
2. メイン領域に当該サービスのページが内蔵 WebView で表示され、ユーザーがログイン。
   ログイン情報（Cookie）はサービスごとに隔離して永続化される。WebView でログインを
   完了できない場合は、通常のブラウザのセッション Cookie の値を貼り付けてもよい。
3. 同じ画面のダウンロード設定パネルで対象（クリエイター・ファイル種別・期間・同時数・
   重複スキップ）を設定。
4. ダウンロード開始で、支援中コンテンツをまとめて取得。複数サービスはキューで順に実行し、
   全サイト一括・毎日の定期実行もできる。
5. 取得物はライブラリ（台帳から構築）で一覧し、投稿詳細で画像・動画・音声のプレビュー、
   zip の解凍、PSD のレイヤー表示ができる。保存フォルダの階層はユーザー設定のパターン
   （初期値 `<サービス>/<クリエイターID>/<年>/<月>/<投稿ID>`）。

## 設計原則

- **ローカル完結**: ネットワーク通信は対象サイトへのアクセスと、起動時の新バージョン確認
  （GitHub の公開 API を読むだけ）のみ。外部サーバへデータを送らない。
- **サービス非依存のコア**: ダウンロードエンジン・ストレージ・UI は特定サイトに依存せず、
  サイトごとの差異は `Service` アダプタに閉じ込める。
- **冪等な再実行**: 何度実行しても、台帳のキー `(サービス, クリエイターID, 投稿ID)` と
  ディスク上のファイルで重複ダウンロードを回避する（[storage-and-dedup.md](storage-and-dedup.md)）。
- **個人利用前提**: [security-and-legal.md](security-and-legal.md) を参照。

## スコープ外（現時点）

- クラウド同期・複数端末間共有
- 支援していない / 課金していないコンテンツの取得
- コンテンツの再配布・公開機能
